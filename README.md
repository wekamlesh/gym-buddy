# Gym Buddy

A private, installable fitness tracker with Cloudflare Pages, D1 cloud storage and offline logging.

The app is in [gym-buddy-pwa/](gym-buddy-pwa/). See the [app README](gym-buddy-pwa/README.md) for local setup and features, and the [Cloudflare deployment guide](gym-buddy-pwa/DEPLOY.md) for private sign-in and multi-device hosting.

The [architecture diagrams](gym-buddy-pwa/ARCHITECTURE.md) explain device storage, cloud sync and automatic DEXA profile initialization.
